# 发布正文

我最近用了一个有点笨的办法：想看懂一个博主，不只看主页简介，而是一直往前翻，直到能看出他反复在讲什么。

《我关注的100位小红书科技博主》#001，我从小盖开始。

这次一共翻到 828 篇公开笔记，从 2025-01-14 到 2026-07-23。近 92 天有 103 篇，热度是 2026-07-26 的一次性快照。

开始前，我以为这是一个更新很快的“AI 工具号”。

翻完以后，我改了判断。小盖更稳定的能力，是去 X、播客、直播和演讲里发现新东西，再把复杂信息压成一个中文读者能马上理解的观点。

最后留在我脑子里的有 5 件事：

1. OpenClaw 真正有想象力的方向，可能不是安装教程，而是预配置好的垂直数字员工。
2. “先采访、后执行”有效，不是因为咒语写得漂亮，而是它把需求澄清变成了 AI 必须完成的前置步骤。
3. Codex 的主场正在离开“只写代码”，但“连接 Kimi”这一步暂时没有找到官方支持说明，我不会直接照抄。
4. 把 Notion、Anthropic、Dyson 三期内容放在一起，反复出现的是 agency、taste，以及人到底还要为结果负责什么。
5. Agent 进入开放环境前，密钥、权限、额度、撤销和审计应该先设计，而不是出事后再补。

还有 3 个地方，我没有装作已经找到答案：OpenClaw 附件里的原始 X 作者、Tim 直播的稳定完整回放，以及 Codex 连接 Kimi 的官方依据。

所以这不是对一个博主盖棺定论，也不是“起底”。它更像一份可以继续补充、也可以被纠正的研究快照。

我已经把代表笔记、原始链接、证据等级和未解决项放进公开 GitHub「AI 创作者档案库」，也做了一个只读查询 Skill：explore-ai-creators。

下一步，我准备先复现“OpenClaw 内容情报员”和“先采访后执行”的 A/B 对照。

下一位，你想让我翻谁？
